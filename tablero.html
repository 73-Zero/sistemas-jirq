1.- Antes de usar el sistema debes saber que tu carpeta descargas será donde se descarguen los archivos según sea el caso

Así también, habrán otros procesos de donde es recomendable subir archivos desde ahí.............

2.- La 1era Opción de Listado de funciones el excel es editable para que puedas agregar o quitar funciones.

3.- La Opción Calcular Datos: es para realizar la suma de los leads brutos, netos, las preventas y las válidas según socio/canal editable.

4.- La Opción de Ayuda Rápida es para realizar trabajos de:
NAC DEACS Anonimizador / Transportar campañas / Alignet / IVR#1 / IVR#2

5.- La Opción de Bigquery conteo: es para revisar las tablas y cantidad de registros por cada una de ellas (conteo de filas), tanto por día, mes y año, dividivo en 3 pestañas para obtener uno día y otro mensual.

6.- También está de Bigquery Meta Entel y Socios : es para verificar los leads, válidas, activas, resumen general esta contiene pestañas donde está agrupado por socios, fuente.

7.- La Opción de Query varios: es para tener aquellas consultas que puedan facilitar alguna tarea y/o obtener alguna respuesta más rápida
